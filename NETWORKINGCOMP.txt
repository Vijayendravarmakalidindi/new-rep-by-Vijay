4. CREATE SIMPLE NETWORK USING PACKET TRACER
1.Launch Packet Tracer. You will see a blank Logical workspace.
2.Add devices — from the Device-Type Selection box, add: 1 PC, 1 Laptop, 1 Wireless Router, 1 Cable Modem, 1 Internet Cloud, 1 Cisco.com Server.
3.Cable the devices:
PC → Wireless Router (FastEthernet0 to Ethernet 1) — Copper Straight-Through
Wireless Router → Cable Modem (Internet port to Port 1) — Copper Straight-Through
Cable Modem → Internet Cloud (Port 0 to Coaxial) — Coaxial cable
Internet Cloud → Cisco.com Server (Ethernet to FastEthernet0) — Copper Straight-Through
4.Configure Wireless Router — click it → GUI tab → Wireless tab → change SSID to HomeNetwork. Then in Setup tab, enable DHCP, set DNS server to 208.67.220.220. Click Save Settings.
5.Configure Laptop — click it → Physical tab → power off → remove Ethernet module → add Wireless WPC300N module → power on → Desktop tab → PC Wireless → Connect tab → select HomeNetwork.
6.Configure PC — click it → Desktop tab → IP Configuration → select DHCP. Open Command Prompt and run ipconfig /all to verify IP in range 192.168.0.x.
7.Configure Internet Cloud — Physical tab → add modules PT-CLOUD-NM-1CX and PT-CLOUD-NM-1CFE → Config tab → Cable: Coaxial→Ethernet, click Add → Ethernet: set Provider Network to Cable.
8.Configure Cisco.com Server — Services tab → DHCP: pool name DHCPpool, gateway 208.67.220.220, DNS 208.67.220.220, start IP 208.67.220.1, mask 255.255.255.0, max users 50, click Add. Then DNS: name Cisco.com, type A Record, address 208.67.220.220, click Add.
9.Verify — On PC, run ipconfig /release then ipconfig /renew. Then run ping Cisco.com — you should see 4 replies.
